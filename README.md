# FindGas ⛽️

An Android app built with Jetpack Compose that helps users find nearby gas stations and navigate to them using Google Maps.

## Features
- Show nearby places (gas, EV chargers, car wash, etc.)
- Filter by category
- Get directions to the nearest result
- Google Maps + Directions API integration

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM
- Retrofit
- Google Maps SDK
- Directions API

## Setup
1. Clone the repo
2. Add your Google Maps API key to `local.properties`
3. Enable Places API & Directions API
4. Run the app
