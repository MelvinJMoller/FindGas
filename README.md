# FindGas

An Android app built with Jetpack Compose that helps users find nearby gas stations and navigate to them using Google Maps.
This app uses Places API and Directions API.

## Features
- Show nearby places and get directions to refuel your car
- Filter by different categories, is your car electric? do you drive a truck?
- Create a roadplanner for a longer roadtrip

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM
- Retrofit
- Google Maps SDK
- Directions API

## Setup
1. Clone the repository
2. Add your Google Maps API key to the `local.properties` file
3. Enable Places API and Directions API
4. Run the app (You are done!)
